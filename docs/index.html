Getting started

Welcome to Comet UI. A premium, light-mode focused design system built for speed and beauty.

Installation

To get started, include our core stylesheets in your project's head:

<link rel="stylesheet" href="comet-ui/src/variables.css">
<link rel="stylesheet" href="comet-ui/src/base.css">
<link rel="stylesheet" href="comet-ui/src/typography.css">
<link rel="stylesheet" href="comet-ui/src/components.css">

    Toast

    Transient notifications from JavaScript. The region is a popover, so toasts appear above open dialogs. Hover or focus pauses the timer.

    CometUI.toast({
  title: 'Saved',
  description: 'Changes are live.',
  variant: 'success',      // default | success | warning | destructive | info
  duration: 5000,          // ms, 0 keeps it open
  action: { label: 'Undo', onClick: () => {} }
});

CometUI.toast.position('top-right'); // top-right | top-center | bottom-right | bottom-center
