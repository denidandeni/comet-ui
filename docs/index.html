Getting started

Welcome to Comet UI. A premium, light-mode focused design system built for speed and beauty.

Installation

To get started, include our core stylesheets in your project's head:

<link rel="stylesheet" href="comet-ui/src/variables.css">
<link rel="stylesheet" href="comet-ui/src/typography.css">
<link rel="stylesheet" href="comet-ui/src/components.css">
