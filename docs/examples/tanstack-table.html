Optional example. @tanstack/table-core handles sorting, global filtering and pagination. Comet UI supplies the markup and styles. The core library has no dependency on TanStack.

This page loads @tanstack/table-core@9.3.1 from jsDelivr. In a bundled project, run npm install @tanstack/table-core and import the same names from '@tanstack/table-core'.
